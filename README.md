# SCT_WD_3 - Ultimate Tic-Tac-Toe Web Application

## 📌 Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship**.

The objective of this task was to build an interactive **Tic-Tac-Toe Web Application** where users can play against the computer while implementing game logic, state management, winning condition detection, and user interaction using JavaScript.

To make the project more engaging and professional than a traditional Tic-Tac-Toe game, several advanced features and modern UI enhancements were added, including multiple difficulty levels, tournament rounds, statistics tracking, achievements, theme switching, animations, sound effects, and local storage support.

## 💡 How It Works

1. The player enters their name before starting the match.
2. The user selects the desired AI difficulty level.
3. The player chooses the tournament format (Best of 3 or Best of 5).
4. The game board becomes active once the match starts.
5. Players take turns placing their symbols on the board.
6. The application continuously tracks the game state.
7. Winning combinations are checked after every move.
8. If a player wins a round, scores are updated automatically.
9. Tournament progress is tracked until the required number of victories is achieved.
10. A winner modal and confetti animation are displayed for victories.
11. Match statistics and achievements are updated and stored locally.
12. Users can restart rounds, begin a new tournament, or continue playing with saved statistics.
